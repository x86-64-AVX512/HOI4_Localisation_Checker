# Конструктор длинных текстов

Вкладка предназначена для русского описания country_event и первой вкладки
welcome screen EaW. Фокусы не входят в эту систему: их проверка и интеграция
с Focus Preview CLI остаются прежними.

## Подготовка

1. Выберите корневую папку мода с common и localisation.
2. Выберите русский .yml, содержащий существующий основной ключ.
3. Выберите ключ из выпадающего списка или введите его и нажмите «Загрузить текст».
4. Укажите уникальный префикс getters: латинские буквы, цифры и подчёркивание,
   с буквой или подчёркиванием в начале.
5. Нажмите «Разбить автоматически». Начальный целевой размер — 4000 UTF-8 байт.
   Соединение частей точно сохраняет текст, пробелы и переводы строк.

Полный редактор показывает настоящие переносы строк. При загрузке исходного
ключа игровые \n декодируются; при сохранении переносы кодируются обратно.
Размер части считается в байтах, а не в буквах. Части от 6144 байт отмечаются
красным и блокируют сохранение.

В списке карточек можно выбрать часть, изменить её текст, применить правку,
разделить у курсора, объединить со следующей и переместить выше/ниже. Разбиение
не разрывает поддерживаемые вставки, ссылки и управляющие последовательности.
После изменения полного текста повторите автоматическое разбиение.

## Ивент страны

Выберите «Ивент страны». Основной ключ должен быть указан в desc ивента
страны, в том числе в поддерживаемом условном блоке desc.
Условия выбора описания, ID и эффекты ивента не изменяются.

Генератор заменяет значение существующего ключа цепочкой
[Root.GetPrefixPart01][Root.GetPrefixPart02], создаёт ключи частей и
defined_text с always = yes. Обычные $PART$ не используются для сборки.

## Вступительный экран

Выберите «Вступительный экран EaW». Основной ключ — EAW_WS_TAB_1_TXT.
Укажите файл, где этот ключ уже определён. Начальная ветка — EQS.
«Загрузить текст» берёт EAW_WS_EQS_desc, а не короткую строку-вызов вкладки.
Для других стран используйте «Добавить страну…» и «Загрузить текст страны…»
либо вставляйте текст самостоятельно.

Каждая страна имеет свои части и original_tag. Общие getters соответствуют
номерам частей. Страна с меньшим числом частей получает пустой результат
в оставшихся getters. У остальных стран первый getter возвращает прежний
GetCountryIntro, остальные — пустую строку. always = yes стоит последним.
Повторный возврат исходного описания и ссылки сборки на себя недопустимы.

Исходные описания стран остаются в файле для других обращений. Внутрь
EAW_WS_EQS_desc общая сборка не помещается: в исследованном варианте
это оставляло обрезание.

## Предпросмотр и сохранение

«Проверить и просмотреть правки…» показывает изменения всех файлов:

- существующий .yml с основным ключом;
- localisation/russian/checker_long_<id>_l_russian.yml с частями;
- common/scripted_localisation/checker_long_<id>.txt с getters;
- .localisation-checker/long_texts.json с проектом сборки.

Сохранение выполняется отдельной кнопкой в предпросмотре. Конфликты ключей и
getters, неоднозначное основное определение, ошибки исходного файла и выход
путей за пределы мода блокируют подготовку. Сохранение проверяет, что файлы
не изменились после предпросмотра. Оригиналы сохраняются с расширением .bak
в .localisation-checker/backups/<дата>/; changes.json перечисляет заменённые
и созданные файлы. Если запись не завершилась, уже записанные файлы
восстанавливаются.

Для ручного восстановления остановите работу с модом, скопируйте .bak на
исходные пути из changes.json без суффикса .bak и удалите перечисленные
новые файлы. Резервные копии не имеют расширения .yml и не участвуют
в последующей рекурсивной проверке локализации.

Проект позволяет снова открыть сборку. Если тексты частей вручную изменены
в сгенерированном .yml, редактор загрузит их актуальные значения.

## Проверки

В сравнении ключей выберите «Мод для scripted-сборок». Части и служебные
fallback-ключи не требуют EN-пар, когда английское описание существует
обычной строкой. Сравнение проверяет реальную структуру файлов; отсутствие
файла проекта не мешает распознаванию простой ручной сборки.

В проверке длины ивентов и вступительных экранов измеряется соединение частей,
а не длина короткой строки из вызовов. Вступительные экраны измеряются
по веткам стран. Части не выдаются за независимые полные описания.
Для выбранного одного файла зависимости собираются из локализации мода.
Повреждённые сборки отмечаются отдельно. Фокусы обрабатываются прежним кодом.

Часть и строка вызовов должны быть меньше 6144 байт. Размер известных $KEY$
подстановок учитывается; для неизвестных параметров/getters точный размер
не утверждается. Цвет, продолжающийся через границу части, отмечается
в предпросмотре.

Обход подтверждён исследованиями на HOI4 1.19.3 для описания ивента страны
и прямой сборки welcome screen EQS. Он не снимает ограничений окна,
прокрутки и разметки. Большое обычное событие может не поместиться даже после
разбиения. После сохранения нужен полный перезапуск игры, проверка стыков,
последнего предложения, кнопок и английского языка; для welcome — также
другой страны с прежним описанием. Сам чекер игру не запускает.
