# Участие в разработке

Спасибо за желание улучшить LocalisationChecker.

## Подготовка окружения

Требуются Windows и Python 3.12 или новее.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

Игровые `.fnt` не хранятся в Git. Для локального запуска подготовьте их по
инструкции в `fonts/README.md`.

## Проверка изменений

Перед отправкой изменений выполните:

```powershell
.\run_tests.ps1
.\.venv\Scripts\python.exe -m compileall -q src app.py tools
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m coverage run -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m coverage report
```

GUI-тесты создают настоящий скрытый Tk-интерфейс, поэтому полный набор
запускается на Windows. Жёсткий минимальный процент покрытия пока не задан:
отчёт используется как исходная точка и не должен заметно ухудшаться.

Если изменение затрагивает сборку, дополнительно выполните `build.ps1` и
проверьте запуск созданного EXE.

## Правила изменений

- Не добавляйте игровые ресурсы, локальные настройки и абсолютные пути.
- Не изменяйте выбранные пользователем файлы локализации: чекер работает
  только на чтение.
- Для новой проверки добавляйте автоматические тесты.
- Пользовательские сообщения и интерфейс сохраняйте на русском языке.
- Обновляйте `CHANGELOG.md`, если изменение заметно пользователю.

## Лицензия вклада

Отправляя изменение, вы соглашаетесь распространять свой вклад на условиях
лицензии 0BSD проекта.
